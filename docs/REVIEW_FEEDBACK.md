1) Dynamic Walkthrough for New Users Observation: 
Currently, there is no dynamic walkthrough available for new users during the
initial use of the app. 

Why It Matters: 
A dynamic walkthrough helps onboard users effectively, guiding them
through key features and functionalities. This feature would prevent new
users from feeling lost or frustrated, improving overall engagement and
satisfaction. 

Possible Enhancements: 
● Interactive Tutorial: Implement a step-by-step tutorial that introduces
users to main features like adding subscriptions, setting alerts, and
managing categories as they navigate through the app for the first
time. ● Skip Option: Provide users the option to skip the tutorial if they prefer
exploring the app independently. ● Help Section: Include a dedicated help section with FAQs and
troubleshooting in case users have questions after the walkthrough. 

2) Comprehensive Currency Support 
Observation: 
The app currently does not provide support for all country currencies. 


Why It Matters: 
Supporting multiple currencies improves accessibility for international users
and enhances user experience by allowing them to track their subscriptions
in their local currency, thereby making the app more versatile. 

Possible Enhancements: 
● Currency Selector: Add a dropdown menu in the settings where users
can select their preferred currency from a comprehensive list of
worldwide currencies. ● Real-Time Currency Conversion: Consider implementing a feature that
provides real-time conversion rates for added convenience, particularly
for users managing subscriptions in different currencies. ● Default Currency Setting: Allow users to set a default currency that can
automatically be applied when adding new subscriptions.

3) "Rate Your App" Button Addition 


Observation: 
There is currently no option for users to easily rate the app under the Settings
menu. 

Why It Matters: 
Encouraging users to rate the app in the Play Store can significantly boost its
visibility and credibility. This is particularly crucial for newly released apps
looking to establish a strong presence. 

Possible Enhancements: 
● Settings Section Update: Add a "Rate Your App" button in the Settings
menu that redirect users directly to the Play Store review page. ● Prompt for Feedback: Consider implementing a subtle prompt after
users have utilized the app several times, reminding them to leave a
review if they enjoy it. 

4) System Theme Option Implementation 


Observation: 
While the app supports Dark Mode and Light Mode, it lacks an option to
enable a System Theme that follows the user's device-wide theme settings. 

Why It Matters: 
Many users prefer their apps to harmonize with their device's overall
aesthetics automatically. This option would enhance user experience by
providing a more seamless interaction with the app. 

Possible Enhancements: 
● System Theme Toggle: Introduce a toggle in the settings that allows
users to select "System Default" as an option, which automatically
adjusts the app’s theme based on the device settings. ● Theme Change Notification: Notify users when the app's theme
changes to match their device's preferences for extra clarity and
satisfaction.
